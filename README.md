# Horario
[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/aleexxvgg/Horario)

Horario is a web application designed to manage and display the academic schedule for the 2nd year SMR (Sistemas Microinformáticos y Redes) course. It provides an interactive and highly customizable interface to keep track of classes, teachers, and exams, with all changes saved directly to your device.

## Features

*   **Interactive Schedule**: View the full weekly class schedule. Click on any class to see its details or edit information like the subject, teacher, and room.
*   **Real-time Class Status**: A dedicated card highlights the class currently in session, complete with a progress bar, or displays the next upcoming class.
*   **Exam Management**: Add, view, and manage your exams. Upcoming exams are flagged directly within the schedule and can be viewed in a dedicated "Exámenes" panel.
*   **Filtering**: Easily filter the schedule to highlight the classes of a specific teacher or subject, helping you focus on what's important.
*   **Persistent Storage**: All your customizations, including schedule changes and added exams, are automatically saved in your browser's local storage.
*   **Theming and Personalization**:
    *   **Color Themes**: Switch between multiple built-in color themes like Cyber, Dark, Ocean, Sakura, and more.
    *   **Futuristic UI**: Toggle a unique "Futuristic" style for a retro-tech interface with a live clock and distinctive visual elements.
    *   **Accessibility**: Adjust the font size and enable a high-contrast mode for improved readability.
*   **Academic Calendar**: A full monthly calendar provides an overview of your schedule and highlights days with scheduled exams.
*   **Quick Links**: Convenient dropdown menus provide direct access to educational platforms like Moodle and Google Classroom.

## Tech Stack

*   **HTML5**
*   **CSS3** (with extensive use of CSS Variables for theming)
*   **Vanilla JavaScript**

## Getting Started

This is a purely static front-end application. No build process or server is required.

1.  Clone the repository:
    ```sh
    git clone https://github.com/aleexxvgg/Horario.git
    ```
2.  Navigate to the project directory:
    ```sh
    cd Horario
    ```
3.  Open the `index.html` file in your web browser to run the application.
